# طموح — حزمة إصلاح نشر V22.1

## نتيجة الفحص
- أرشيف V22 السابق سليم ويمكن فكّه، وملفات JS اجتازت `node --check`.
- عند فحص المستودع `BODA242010-jpg/tmoh9` لم تظهر ملفات `tmoh-v20.js` و`tmoh-v21.js` و`tmoh-v22.js` ولا صور `assets` في جذر الفرع `main`؛ لذلك النسخة الجديدة لا تظهر بالشكل المطلوب.
- الحزمة **ليست نسخة كاملة مستقلة**؛ الملفات الأصلية للموقع مثل `app.js` و`style.css` و`cloud-auth.js` و`tmoh-study.js` ضرورية. لا تحذفها.
- تم إصلاح تثبيت Service Worker ليستخدم `Promise.allSettled` ولا يفشل التثبيت كله بسبب صورة أو ملف مفقود، مع تجديد رقم التخزين المؤقت.

## رفع الملفات بالترتيب الصحيح
1. فك ZIP على جهازك.
2. افتح مستودع `https://github.com/BODA242010-jpg/tmoh9` ثم فرع `main`.
3. اختر Add file > Upload files، وحدد **المحتويات داخل ZIP** وليس ZIP نفسه ولا مجلدًا أبًا يحتوي الملفات.
4. ارفع الملفات إلى نفس مجلد `index.html`، مع الحفاظ على بنية `assets/tmoh-student.png` و`assets/tmoh-mountains.svg`. وافق على استبدال الملفات المتطابقة فقط.
5. لا تمسح الملفات الأصلية غير الموجودة في ZIP. بعد الـ commit انتظر اكتمال GitHub Pages من Actions.
6. افتح `https://boda242010-jpg.github.io/tmoh9/health-check.html` وتأكد من علامات ✅.
7. افتح `https://boda242010-jpg.github.io/tmoh9/`، واعمل تحديثًا قويًا Ctrl+Shift+R أو جرّب نافذة خاصة. إذا احتفظ الموقع بالنسخة القديمة، امسح بيانات هذا الموقع المحدد فقط بعد أخذ نسخة احتياطية من بيانات الطلاب؛ فحذف بيانات الموقع قد يمسح تقدمهم المحلي.

## أهم شيء
في حالة فشل جميع الروابط أو 404، افحص Settings > Pages: مصدر النشر هو `main` / `(root)`، مع وجود `index.html` في الجذر. لا تعطل Cloudflare Worker أو الشات بوت، ولا تضع مفاتيح API في ملفات الواجهة.

ملف `health-check.html` للفحص المؤقت فقط، ويمكن حذفه بعد التأكد من نجاح النشر.
